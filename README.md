# Gatemate Learning – LMS Website

A complete, modern, and responsive Learning Management System (LMS) website for **Gatemate Learning Private Limited**.  
Built with pure HTML, CSS, and JavaScript – ready to host on GitHub Pages with your custom domain `gatemate.tech`.

## Features

- **Landing Page** with hero, stats, features, courses, testimonials, and CTA.
- **About Us** – team, mission, and values.
- **Gallery** – image grid with hover effects.
- **Contact** – integrated Google Map, contact form, and details.
- **Student / Teacher / Admin Login** – role‑specific login pages.
- **Student Enrolment** – functional enrolment form.
- **Fully Responsive** – works on all devices.
- **Professional UI/UX** – clean, modern, and accessible.

## Deployment to GitHub Pages

1. Create a new repository on GitHub (e.g., `gatemate-learning`).
2. Upload all the files from this project.
3. Go to **Settings > Pages** and set the source to `main` branch.
4. (Optional) Add your custom domain `gatemate.tech` in the Pages settings.
5. Configure your domain's DNS with the GitHub IP addresses.

## Custom Domain Setup

- Add a `CNAME` file in the root with the content: `gatemate.tech`
- In your domain registrar, point the `A` records to GitHub's IPs:
  - `185.199.108.153`
  - `185.199.109.153`
  - `185.199.110.153`
